# 評分與能力驗收

總分 100。每項依完整性、正確性與能否解釋結果評分；建議 70 分及格，並同時滿足下方必要條件。

| 項目 | 分數 | 完整成果 |
|---|---:|---|
| 論文導讀 | 15 | 問題、模型、兩張圖、證據頁碼與限制 |
| Layout | 10 | 參數化腳本、尺寸、pin／net、幾何檢查 |
| C 與 EC | 15 | 真實矩陣、節點與邊界、正確單位、收斂 |
| Eigenmode | 15 | 模態場圖、正確辨識、mesh／box 檢查 |
| S21／linewidth | 15 | 複數原始資料、模型、殘差、掃頻與 mesh 檢查 |
| Spectrum／ZZ | 15 | Hamiltonian、態標籤、混合區、g=0 與截斷比較 |
| Pulse | 10 | 脈衝校準、population／leakage、耗散、solver 比較 |
| 可重現性 | 5 | 環境、參數來源、執行方法與結果一致 |

## 必要條件

- 不混淆 Hz/rad·s⁻¹、ns/μs、EC 與 EC/h。
- 不把示範資料稱為真實 solver 結果，不把 |1> population 稱為 gate fidelity。
- 完整電磁模擬能力認證需真實 solver 設定、結果與收斂；沒有 solver 時在成績上標註「數值部分完成，電磁部分未驗收」。

## 現場實作題（建議 60–90 分鐘，另計求解時間）

1. 講師指定一組新 pad 尺寸，學員重建 layout 並指出預期 EC 趨勢。
2. 給一組未見過的 C CSV，要求確認格式、算 EC、解釋接地與浮接邊界差異。
3. 給兩張 eigenmode 場圖，辨識 qubit-like／resonator-like，說明不能只看頻率。
4. 給複數 S21（可刻意加入 delay 或多模），要求先判斷簡化模型是否適用，再擬合及換算 κ。
5. 改 QuTiP g、detuning 與 pulse width，先預測趨勢再執行；指出哪個區域 ZZ 標籤不可靠。

真實求解的操作可另外預約：要求學員從新幾何完成 net/port、mesh 與匯出，講師檢查原始 project，而非僅看事先準備的圖片。
